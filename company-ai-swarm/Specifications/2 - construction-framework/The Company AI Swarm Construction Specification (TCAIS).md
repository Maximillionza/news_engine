# The Company AI Swarm Construction Specification (TCAIS)

## Version 1.0

## Purpose: AI-Executable Build Directive


# 1. SYSTEM IDENTITY

## Name

The Company

## Type

AI Enterprise Operating System

## Objective

Construct an AI swarm modelled after a human enterprise structure.

The system must operate as a governed organization consisting of:

- Executive intelligence.

- Operational orchestration.

- Specialized departments.

- Autonomous agents.

- Memory systems.

- Knowledge systems.

- Workflows.

- Governance controls.


# 2. PRIMARY BUILD INSTRUCTION

You are an AI software architect and engineering system.

Your objective is to construct The Company according to these rules.

Do not create a collection of independent agents.

Create an enterprise operating system where agents function as organizational employees within defined structures.

# 4. NON-NEGOTIABLE ARCHITECTURAL RULES

## RULE-001 — Strategic Separation

The Director defines:

- Vision.

- Strategic objectives.

- Major decisions.

The Director does not perform operational execution.


## RULE-002 — Operational Control

The COO is the operational controller.

All work allocation flows through the COO.

Agents do not independently create organizational objectives.


## RULE-003 — Task-Based Intelligence Routing

Model selection happens per task.

Never assign a model based only on project type.

Evaluation:

```
`Task`


`↓`


`Complexity`


`↓`


`Risk`


`↓`


`Required capability`


`↓`


`Required reasoning level`


`↓`


`Model selection`
```

Simple tasks use efficient models.

Complex tasks use advanced reasoning models.


## RULE-004 — Memory Is Context, Not Truth

Memory provides information.

Memory does not create assumptions.

Previous projects may influence future decisions only when conditions match.

Example:

Incorrect:

```
`Previous project had POPIA issues.`


`Therefore:`


`All projects have POPIA issues.`
```

Correct:

```
`Previous project revealed POPIA risks.`


`Evaluate whether those conditions exist in the current task.`
```


## RULE-005 — Knowledge and Memory Separation

Knowledge:

- Validated facts.

- Standards.

- Policies.

- Enterprise information.

Memory:

- Experiences.

- Past interactions.

- Lessons.

- Context.

They must not be combined without validation.


## RULE-006 — Everything Must Be Observable

Every:

- Decision.

- Agent action.

- Workflow.

- Model call.

- Memory access.

must be traceable.
