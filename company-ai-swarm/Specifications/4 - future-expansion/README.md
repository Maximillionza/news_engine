# Tier 4 — Future Expansion

These specifications were reviewed during the repository-documents reconciliation pass and
judged genuinely valuable but **not part of the MVS-canonical MVP**. They are kept for
reference when the corresponding capability is actually built:

- **SDK / Plugin / Marketplace / API / Event Bus / Service Bus** (EAAS, EEBS, EMAS
  [marketplace], EPAS, ESDKS, ESBS) — EIB Phase 3 "Enterprise Capability Expansion" content.
- **Compiler-track architecture** (EMMS, CEDLS, EBAS, ERAS, and MCDP's construction
  methodology) — deferred per the explicit ruling that the MVP is hand-built directly
  (ABMEP/CCBP/TCABS), not compiled from a CEDL definition through the EIR→Compiler→Builder
  pipeline. If that pipeline is ever pursued, these five documents plus the already-merged
  EIR (Specifications/2) and ECAS (Specifications/2) are the starting point.

None of these were merged or edited during reconciliation — they are unchanged from the
source repository-documents folder. Do not treat them as currently authoritative; check them
against whatever Tier 1-3 specifications exist at the time they become relevant, since this
reconciliation pass did not resolve their internal consistency with each other or with the
rest of the corpus beyond what's noted in each document's own content.
