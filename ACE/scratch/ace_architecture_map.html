What each color means for you, tuning-wise

Green box parameters (Section 1–12 of the Tuning Map — risk, ATR, bias, sessions, scoring, regime profiles, execution resilience) are live: change one and your next trade behaves differently.

Amber box parameters (Tuning Map section 13–14 — V4 authority, adaptive thresholds, evidence detectors) currently only reshape what gets logged and what the adaptive engine learns from. They become live the moment InpAceV4Mode moves to CONDITIONAL or ACTIVE — at which point the amber path can jump straight to WAIT_EXECUTION, same as the green one.

The one thing to hold onto — right now you effectively have one trading system and one research system running on the same tick, sharing a chart and a magic number, but only one of them can pull a trigger. Every "why did it enter here" question should start on the green side; every "should this become an archetype" question lives on the amber side.
