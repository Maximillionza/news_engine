The AI Builder Master Execution Package defines the instructions for an AI engineering system to construct The Company AI Swarm.

The package is designed for execution by:

- AI coding agents.

- Autonomous development systems.

- Software engineering copilots.

- Human engineering teams assisted by AI.

- Codex.

# 4. Core Construction Rules

## Rule 001 — Preserve Architecture

All generated code must map to an existing architectural component.


## Rule 002 — Build Incrementally

Never attempt uncontrolled full-system generation.

Build in verified stages.


## Rule 003 — Generate Complete Components

Every component requires:

- Source code.

- Configuration.

- Documentation.

- Tests.


## Rule 004 — Maintain Traceability

Every implementation must identify:

- Architecture source.

- Purpose.

- Dependencies.

- Owner.


## Rule 005 — Security First

Every component requires:

- Identity.

- Permissions.

- Logging.

- Validation.
