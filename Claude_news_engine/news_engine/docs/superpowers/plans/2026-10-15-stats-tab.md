# Stats Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Stats tab (Combined / Tier 1 / News sentiment) that scores Tier 1, News-only and a 70/30 Combined predictor against real releases, with a Forecast/Actual/Predicted line chart, per-metric component info icons, and a frozen backfill of rule-based Tier 1 calls.

**Architecture:** A read-only `webapp/stats_service.py` joins `event_history` (dashboard DB) with `predictions`, `print_predictions`, `tier1_predictions` and a new append-only `tier1_nowcast_snapshots` table (backtest DB), using pure rule/method modules (`stats_rules.py`, `stats_methods.py`). Flask routes serve explicit-field JSON; a new `webapp/static/js/stats/` module renders the tab. The backfill is a separate script behind a pluggable nowcast provider so the Phase 0 outcome cannot block the rest.

**Tech Stack:** Python 3 / Flask / SQLite (`sqlite3.Row`), pytest; vanilla ES modules, `node --test`; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-15-stats-tab-design.md` (commit 48d00ab). Read it first; this plan implements it.

## Global Constraints

- Right/Wrong is decided by **direction against the Forecast**, never by closeness of the number; size of miss is shown separately. (D5)
- `tol` = one rounding step of the forecast's published precision; `side(x)` is 0 when `|x − F| < tol`. (§4)
- Combined = **70% Tier 1 + 30% News** (`0.70·s1 + 0.30·sN`); the weight is fixed, never tuned on results, and revisited on **2027-01-15**. (D3)
- Combined has **no "Conflicting" state**. If news is missing, `S = s1` and the row is flagged `news_missing`. If Tier 1 is not tracked, Combined is `n/a`. (D4, §4.1)
- Percentages are always shown with the count (`8 of 10`); **no percentage under 20 scored events**. (D8)
- Every row in `event_history` appears (287 titles / 646 occurrences at spec time); Tier 1 is greyed "Not tracked by Tier 1" where no rule exists. (D2)
- No news exists before **2026-08-12**; selecting an earlier month on News or Combined shows: "No news articles exist before 12 Aug 2026. Combined for these months is Tier 1 only." (D7)
- Reconstructed rows are tagged `reconstructed` with: "Reconstructed after the fact from the stated rule; not a live call." Scoreboard footnote: "Weights fixed at 70/30 until the 2027-01-15 review."
- Oil/gasoline are **not** separate Tier 1 weights (already nowcast inputs). Brent/gasoline move since the snapshot is information at 0% weight. (D10, §6)
- `predicted_direction`, live scoring tables and the existing History/Dashboard code paths are **never modified**. Stats writes only its own new table.
- Market impact wording: Buy / Sell / No clear lean per tracked symbol, followed by "Typical reaction, not a trade signal."
- All timestamps stored UTC ISO-8601; displayed times are SAST (UTC+2).
- Every task ends with a commit on branch `stats-tab` in a dedicated worktree (Task 0 step 1). Never commit news_engine work in the shared checkout.

## Review Focus

Failure modes the spec implies that no feature task would otherwise exercise (each is pinned by a test in the owning task). Duplicate occurrences are impossible: `event_history` has `UNIQUE(event_title, event_time_utc)`.

1. A forecast/actual string that cannot be parsed (`"N/A"`, `"1.2|0.9"`, empty) — row stays listed as "not scoreable", never crashes the page. (Task 1, Task 5)
2. A future event (actual `None`) — shows "pending", no Right/Wrong, no chart point. (Task 5)
3. A snapshot dated **after** the release must never be scored (lookahead guard). (Task 4)
4. Exactly 20 scored events shows a percentage; 19 shows only `k of n`. (Task 5)
5. Year/month filter that matches nothing — empty-state text and an empty (not broken) chart. (Task 5, Task 7)

# webapp/stats_rules.py
"""
Pure scoring rules for the Stats tab (docs/superpowers/specs/2026-10-15-stats-tab-design.md §4).
Right/Wrong is decided by DIRECTION against the Forecast, never by closeness of the number.
"""
from __future__ import annotations

import re
from typing import Optional

_NUMBER = re.compile(r"^\s*(-?\d+(?:\.\d+)?)\s*(?:[KMBT]|%)?\s*$", re.IGNORECASE)
_EPS = 1e-9


def parse_number(text: Optional[str]) -> Optional[float]:
    """'0.6%' -> 0.6, '89K' -> 89.0 (unit kept as published, not rescaled). Unreadable -> None."""
    if text is None:
        return None
    match = _NUMBER.match(str(text))
    return float(match.group(1)) if match else None


def decimals_of(text: Optional[str]) -> Optional[int]:
    if parse_number(text) is None:
        return None
    number = re.search(r"-?\d+(?:\.(\d+))?", str(text))
    return len(number.group(1)) if number and number.group(1) else 0


def tolerance(forecast_text: Optional[str]) -> Optional[float]:
    """One rounding step of the forecast's own published precision (0.3% -> 0.1, 89K -> 1)."""
    decimals = decimals_of(forecast_text)
    return None if decimals is None else 10.0 ** (-decimals)


def side(value: float, forecast: float, tol: float) -> int:
    """-1 below, 0 in line (less than one step away), +1 above. _EPS absorbs float noise (0.4-0.3)."""
    if abs(value - forecast) < tol - _EPS:
        return 0
    return 1 if value > forecast else -1


def judge(predicted_side: Optional[int], actual_side: Optional[int]) -> Optional[str]:
    if predicted_side is None or actual_side is None:
        return None
    return "right" if predicted_side == actual_side else "wrong"


def miss_size(predicted: Optional[float], actual: Optional[float]) -> Optional[float]:
    if predicted is None or actual is None:
        return None
    return abs(predicted - actual)
```

# webapp/stats_methods.py
"""
Method maths for the Stats tab (spec §4.1). Pure except for reading two existing mapping tables.
Combined = 70% Tier 1 + 30% News; the weight is fixed in advance and revisited on 2027-01-15.
"""
from __future__ import annotations

import statistics
from dataclasses import dataclass
from typing import Optional

from config.settings import EVENT_SURPRISE_DIRECTION
from webapp.history import _implied_surprise_direction
from webapp.symbols import UnrecognizedSymbolError, classify_symbol

TIER1_WEIGHT = 0.70
NEWS_WEIGHT = 0.30
MIN_HISTORY_FOR_SCALE = 3


def news_scale(prior_abs_surprises: list[float]) -> Optional[float]:
    """Median |actual - forecast| over occurrences BEFORE this one (no lookahead). Assumption: labelled on the chart."""
    if len(prior_abs_surprises) < MIN_HISTORY_FOR_SCALE:
        return None
    return statistics.median(prior_abs_surprises)


def tier1_surprise(nowcast: Optional[float], forecast: Optional[float]) -> Optional[float]:
    return None if nowcast is None or forecast is None else nowcast - forecast


def news_surprise(lean: Optional[float], scale: Optional[float]) -> Optional[float]:
    return None if lean is None or scale is None else lean * scale


@dataclass(frozen=True)
class CombinedResult:
    surprise: float
    news_missing: bool


def combine(s1: Optional[float], sn: Optional[float]) -> Optional[CombinedResult]:
    """No Tier 1 -> None (Combined is n/a). No news -> Tier 1 only, flagged. Never a 'conflicting' state."""
    if s1 is None:
        return None
    if sn is None:
        return CombinedResult(surprise=s1, news_missing=True)
    return CombinedResult(surprise=TIER1_WEIGHT * s1 + NEWS_WEIGHT * sn, news_missing=False)


def news_lean(
    event_title: str, print_side: Optional[str], print_confidence: Optional[float],
    acc_direction: Optional[str], acc_probability: Optional[float],
) -> Optional[float]:
    """
    Lean in [-1, +1]; + means 'hotter/higher than forecast'. Rule R3, fixed before results are viewed:
    1) a print call that takes a side wins (strength = its confidence);
    2) otherwise the XAUUSD accumulator prediction, mapped to a surprise side, strength |2p-1|.
    """
    if print_side in ("higher", "lower") and print_confidence is not None:
        strength = max(0.0, min(1.0, float(print_confidence)))
        return strength if print_side == "higher" else -strength
    if acc_direction in ("bullish", "bearish") and acc_probability is not None:
        implied = _implied_surprise_direction(event_title, "XAUUSD", acc_direction)
        if implied is None:
            return None
        strength = abs(2 * float(acc_probability) - 1)
        return strength if implied == "higher" else -strength
    return None


def market_lean(event_title: str, surprise_side: int, symbol: str) -> str:
    """'buy' | 'sell' | 'mixed' for one symbol given the surprise side (+1 higher, -1 lower, 0 in line)."""
    surprise_map = EVENT_SURPRISE_DIRECTION.get(event_title)
    if surprise_map is None or surprise_side == 0:
        return "mixed"
    usd_bullish = (surprise_side > 0) == (surprise_map == "higher_bullish")
    try:
        relationship = classify_symbol(symbol).usd_relationship
    except UnrecognizedSymbolError:
        return "mixed"
    if relationship is None:
        return "mixed"
    if relationship == "direct":
        return "buy" if usd_bullish else "sell"
    return "sell" if usd_bullish else "buy"   # inverse and risk_sentiment flip against USD
```

```python
_SNAPSHOT_KINDS = ("live", "reconstructed")


def record_nowcast_snapshot(
    conn: sqlite3.Connection, event_title: str, event_time_utc: dt.datetime, nowcast_value: float,
    as_of_utc: dt.datetime, source: str, kind: str, rule_version: Optional[str] = None,
    inputs: Optional[dict] = None,
) -> int:
    """
    Append-only (spec 2026-10-15 ruling R1): a snapshot is never updated. A duplicate
    (title, release, as_of, kind) is ignored, so re-running a backfill is idempotent and a rule
    change must write a new rule_version/as_of rather than rewrite history.
    """
    if kind not in _SNAPSHOT_KINDS:
        raise ValueError(f"kind must be one of {_SNAPSHOT_KINDS}, got {kind!r}")
    conn.execute(
        "INSERT OR IGNORE INTO tier1_nowcast_snapshots (event_title, event_time_utc, nowcast_value, "
        "as_of_utc, source, kind, rule_version, inputs_json, recorded_at_utc) VALUES (?,?,?,?,?,?,?,?,?)",
        (event_title, event_time_utc.isoformat(), float(nowcast_value), as_of_utc.isoformat(), source, kind,
         rule_version, None if inputs is None else json.dumps(inputs, sort_keys=True),
         dt.datetime.now(dt.timezone.utc).isoformat()),
    )
    conn.commit()
    row = conn.execute(
        "SELECT id FROM tier1_nowcast_snapshots WHERE event_title=? AND event_time_utc=? AND as_of_utc=? AND kind=?",
        (event_title, event_time_utc.isoformat(), as_of_utc.isoformat(), kind),
    ).fetchone()
    return row["id"]


def get_scored_nowcast_snapshot(
    conn: sqlite3.Connection, event_title: str, event_time_utc: dt.datetime,
    kinds: tuple[str, ...] = _SNAPSHOT_KINDS,
) -> Optional[sqlite3.Row]:
    """
    The snapshot that gets scored: the LATEST as_of_utc that is <= the release time (no lookahead),
    live preferred over reconstructed. None if there is no such snapshot.
    """
    placeholders = ",".join("?" for _ in kinds)
    return conn.execute(
        f"SELECT * FROM tier1_nowcast_snapshots WHERE event_title = ? AND event_time_utc = ? "
        f"AND as_of_utc <= ? AND kind IN ({placeholders}) "
        "ORDER BY CASE kind WHEN 'live' THEN 0 ELSE 1 END, as_of_utc DESC, id DESC LIMIT 1",
        (event_title, event_time_utc.isoformat(), event_time_utc.isoformat(), *kinds),
    ).fetchone()
```

    news: Optional[MethodCall]
    combined: Optional[MethodCall]
    nowcast_as_of_utc: Optional[str]
    pre_news_period: bool


def _parse_time(value: str) -> dt.datetime:
    parsed = dt.datetime.fromisoformat(value)
    return parsed if parsed.tzinfo else parsed.replace(tzinfo=dt.timezone.utc)


def _call(predicted: Optional[float], surprise: Optional[float], forecast: float, tol: float,
          actual: Optional[float], title: str, note: Optional[str] = None, kind: Optional[str] = None,
          explicit_side: Optional[int] = None) -> MethodCall:
    predicted_side = explicit_side if explicit_side is not None else (
        None if predicted is None else side(predicted, forecast, tol))
    actual_side = None if actual is None else side(actual, forecast, tol)
    leans = {} if predicted_side is None else {s: market_lean(title, predicted_side, s) for s in TRACKED_SYMBOLS}
    return MethodCall(
        predicted=predicted, surprise=surprise, side=predicted_side,
        verdict=judge(predicted_side, actual_side), miss=miss_size(predicted, actual),
        leans=leans, note=note, kind=kind,
    )


def build_rows(dash_conn, bt_conn, year: Optional[int] = None, month: Optional[int] = None,
               event_title: Optional[str] = None) -> list[StatsRow]:
    raw = dash_conn.execute("SELECT * FROM event_history ORDER BY event_time_utc, event_title").fetchall()   # UNIQUE(title, time): no duplicates
    titles = sorted({r["event_title"] for r in raw})
    try:
        prints = get_latest_print_predictions_bulk(bt_conn, titles)
    except Exception:  # noqa: BLE001 -- fail open: no news signal, rows still render
        logger.warning("print predictions lookup failed", exc_info=True)
        prints = {}

    history: dict[str, list[float]] = {}
    out: list[StatsRow] = []
    for r in raw:
        title, when = r["event_title"], _parse_time(r["event_time_utc"])
        try:
            row = _build_one(bt_conn, r, title, when, history.get(title, []), prints)
        except Exception:  # noqa: BLE001 -- one bad row must not break the tab
            logger.warning("stats row failed for %s %s", title, when, exc_info=True)
            row = _not_scoreable(r, title, when)
        out.append(row)
        f, a = parse_number(r["forecast"]), parse_number(r["actual"])
        if f is not None and a is not None:
            history.setdefault(title, []).append(abs(a - f))

    def keep(row: StatsRow) -> bool:
        return ((year is None or row.event_time_utc.year == year)
                and (month is None or row.event_time_utc.month == month)
                and (event_title is None or row.event_title == event_title))
    return [row for row in out if keep(row)]


def _not_scoreable(r, title, when) -> StatsRow:
    return StatsRow(title, when, r["forecast"], r["actual"], None, None, None, "not_scoreable",
                    False, None, None, None, None, when < NEWS_START_UTC)


def _build_one(bt_conn, r, title: str, when: dt.datetime, prior: list[float], prints) -> StatsRow:
    forecast, actual = parse_number(r["forecast"]), parse_number(r["actual"])
    tol = tolerance(r["forecast"])
    if forecast is None or tol is None:
        return _not_scoreable(r, title, when)
    status = "pending" if actual is None else "scored"
    pre_news = when < NEWS_START_UTC

    tier1: Optional[MethodCall] = None
    tier1_tracked = False
    nowcast_as_of = None
    snapshot = get_scored_nowcast_snapshot(bt_conn, title, when) if title in NOWCAST_EVENTS else None
    s1 = None
    if snapshot is not None:
        nowcast = snapshot["nowcast_value"]
        s1 = tier1_surprise(nowcast, forecast)
        nowcast_as_of = snapshot["as_of_utc"]
        tier1 = _call(nowcast, s1, forecast, tol, actual, title, kind=snapshot["kind"])
        tier1_tracked = True
    else:
        logged = get_latest_tier1_prediction_for_occurrence(bt_conn, title, "XAUUSD", when)
        if logged is not None:
            implied = _implied_surprise_direction(title, "XAUUSD", logged.predicted_direction) \
                if logged.predicted_direction in ("bullish", "bearish") else None
            sd = {"higher": 1, "lower": -1}.get(implied, 0 if logged.predicted_direction == "neutral" else None)
            tier1 = _call(None, None, forecast, tol, actual, title, note="hand-logged", explicit_side=sd)
            tier1_tracked = True
        else:
            tier1_tracked = title in NOWCAST_EVENTS      # tracked but no snapshot yet: row shows no call

    print_row = prints.get((title, when.isoformat()))
    acc = get_latest_prediction_for_occurrence(bt_conn, title, "XAUUSD", when)
    lean = news_lean(
        title, getattr(print_row, "predicted_vs_forecast", None), getattr(print_row, "confidence", None),
        getattr(acc, "direction", None), getattr(acc, "probability", None),
    )
    scale = news_scale(prior)
    sn = news_surprise(lean, scale)
    news = None
    if sn is not None:
        news = _call(forecast + sn, sn, forecast, tol, actual, title, note="scaled")

    combined = None
    blended = combine(s1, sn)
    if blended is not None:
        combined = _call(forecast + blended.surprise, blended.surprise, forecast, tol, actual, title,
                         note="news_missing" if blended.news_missing else None)

    return StatsRow(title, when, r["forecast"], r["actual"], forecast, actual, tol, status,
                    bool(tier1_tracked), tier1, news, combined, nowcast_as_of, pre_news)


def _unit(rows: list[StatsRow]) -> str:
    for row in rows:
        text = (row.forecast_text or "").strip()
        if text and not text[-1].isdigit():
            return text[-1]
    return ""


def build_chart(rows: list[StatsRow], method: str) -> dict:
    if method not in METHODS:
        raise ValueError(f"method must be one of {METHODS}")
    points = []
    for row in rows:
        if row.status == "not_scoreable":
            continue
        call = getattr(row, method)
        points.append({
            "month": row.event_time_utc.strftime("%Y-%m"), "event_time_utc": row.event_time_utc.isoformat(),
            "forecast": row.forecast, "actual": row.actual,
            "predicted": None if call is None else call.predicted,
            "verdict": None if call is None else call.verdict,
        })
    return {"method": method, "unit": _unit(rows), "points": points}


def build_scoreboard(rows: list[StatsRow]) -> dict:
    methods = {}
    for name in METHODS:
        scored = right = 0
        misses: list[float] = []
        for row in rows:
            call = getattr(row, name)
            if call is None or call.verdict is None:
                continue
            if name in ("news", "combined") and call.note == "news_missing":
                if name == "news":
                    continue
            scored += 1
            right += call.verdict == "right"
            if call.miss is not None:
                misses.append(call.miss)
        shown = scored >= MIN_SCORED_FOR_PERCENT
        methods[name] = {
            "scored": scored, "right": right,
            "accuracy": (right / scored) if shown else None, "accuracy_shown": shown,
            "mean_miss": (sum(misses) / len(misses)) if misses else None,
        }
    return {"methods": methods, "min_for_percent": MIN_SCORED_FOR_PERCENT}
```

# scripts/backfill_tier1_reconstructed.py
"""
Frozen, rule-based backfill of Tier 1 nowcast snapshots (spec §8). Never invents data: where the
provider has nothing the occurrence is skipped; a value dated after the release is refused.
Usage: python scripts/backfill_tier1_reconstructed.py nowcasts.csv v1 2026-01-01 2026-08-12
"""
from __future__ import annotations

import csv
import datetime as dt
import sys
from pathlib import Path
from typing import Optional, Protocol

from scoring import backtest_store
from webapp import store as dash_store
from webapp.stats_service import NOWCAST_EVENTS

UTC = dt.timezone.utc


class NowcastProvider(Protocol):
    def nowcast_before(self, event_title: str, release_utc: dt.datetime) -> Optional[tuple[float, dt.datetime, str]]: ...


class FileNowcastProvider:
    def __init__(self, csv_path: Path):
        self._rows: dict[tuple[str, str], list[tuple[dt.datetime, float, str]]] = {}
        with open(csv_path, newline="", encoding="utf-8") as handle:
            for row in csv.DictReader(handle):
                key = (row["event_title"], dt.datetime.fromisoformat(row["release_utc"]).isoformat())
                self._rows.setdefault(key, []).append(
                    (dt.datetime.fromisoformat(row["as_of_utc"]), float(row["value"]), row["source"]))

    def nowcast_before(self, event_title, release_utc):
        candidates = [c for c in self._rows.get((event_title, release_utc.isoformat()), []) if c[0] <= release_utc]
        if not candidates:
            return None
        as_of, value, source = max(candidates, key=lambda c: c[0])
        return value, as_of, source


def run_backfill(dash_conn, bt_conn, provider: NowcastProvider, rule_version: str,
                 since: dt.datetime, until: dt.datetime) -> dict:
    result = {"written": 0, "skipped_no_data": 0, "skipped_lookahead": 0}
    rows = dash_conn.execute(
        "SELECT DISTINCT event_title, event_time_utc FROM event_history WHERE event_time_utc >= ? AND event_time_utc < ? "
        "ORDER BY event_time_utc", (since.isoformat(), until.isoformat())).fetchall()
    for r in rows:
        if r["event_title"] not in NOWCAST_EVENTS:
            continue
        release = dt.datetime.fromisoformat(r["event_time_utc"])
        found = provider.nowcast_before(r["event_title"], release)
        if found is None:
            result["skipped_no_data"] += 1
            continue
        value, as_of, source = found
        if as_of > release:
            result["skipped_lookahead"] += 1
            continue
        backtest_store.record_nowcast_snapshot(
            bt_conn, r["event_title"], release, value, as_of, source, "reconstructed", rule_version=rule_version)
        result["written"] += 1
    return result


if __name__ == "__main__":
    csv_path, version, start, end = sys.argv[1:5]
    out = run_backfill(
        dash_store.get_connection(), backtest_store.get_connection(), FileNowcastProvider(Path(csv_path)), version,
        dt.datetime.fromisoformat(start).replace(tzinfo=UTC), dt.datetime.fromisoformat(end).replace(tzinfo=UTC))
    print(out)
```

from __future__ import annotations

import argparse
import datetime as dt
from typing import Optional

from scoring import backtest_store


def capture(conn, event_title: str, release_utc: dt.datetime, value: float,
            as_of_utc: Optional[dt.datetime] = None, source: str = "cleveland_fed_nowcast") -> int:
    as_of = as_of_utc or dt.datetime.now(dt.timezone.utc)
    if as_of > release_utc:
        raise ValueError("as_of_utc is after the release: a snapshot taken after the print cannot be scored")
    return backtest_store.record_nowcast_snapshot(conn, event_title, release_utc, value, as_of, source, "live")


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--event", required=True)

    parser.add_argument("--value", required=True, type=float)

    row_id = capture(
        backtest_store.get_connection(), args.event, dt.datetime.fromisoformat(args.release), args.value,
        dt.datetime.fromisoformat(args.as_of) if args.as_of else None, args.source)
    print(f"recorded snapshot id={row_id}")


if __name__ == "__main__":
    main()
