# Developing Committee Playbook

Accumulated process knowledge for the Developing Committee, across all
case studies. This is NOT case content — no idea names, industries,
mechanics, or identifying specifics belong here, even in generalized
form. If a lesson is specific enough that someone who knows the case
portfolio could guess which case it came from, it does not belong here.

Every entry below was proposed by the Developing Committee at the end of
an engagement and explicitly approved by the user before being added. The
Developing Committee does not write to this file itself.
